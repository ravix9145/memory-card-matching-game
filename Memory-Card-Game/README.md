### Project Description



Memory Card Matching Game is a Python GUI application developed using Tkinter. The player flips cards and attempts to find matching pairs. The game demonstrates the use of lists, buttons, event handling, and state management.



#### Features



\* Random card arrangement

\* Interactive graphical interface

\* Matching pair detection

\* Winning message

\* Restart option



#### Technologies Used



\* Python

\* Tkinter

\* Random Module
